Instructions to install the testing ZIP:
Put gunslugs.zip in PortMaster/autoinstall and run PortMaster.

Game: Gunslugs
Source: https://github.com/ronaxdevil/gunslug_port

Buy and install Gunslugs 3.2.4 from the Epic Games Store mobile app on Android.
Use AnExplorer > Apps > long-press Gunslugs > Backup. Copy the resulting APK
from Internal Storage/Backup/Apps into ports/gunslugs/gamedata, then launch the port.
extracted.sh builds GAME.JAR and extracts assets on the handheld.

PC alternative: GOG Gunslugs 3.3.0, build ID 58441296934612083.
Copy gunslugs.dat from the Windows installation into ports/gunslugs/gamedata.
First launch prepares gamedata/pc/GAME.JAR on the handheld. PC data takes
priority if both inputs are present. PC saves are in gunslugs/saves/pc.

controls:
D-pad / left stick: Move / menu navigation; Up jumps |
A / X / R2: Fire / confirm
B / L2: Jump
Y / R1: Options
Start: Confirm
Select / L1: Back / pause
Select + Start: Exit through PortMaster
