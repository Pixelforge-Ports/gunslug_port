MODIFICATION AND REPLACEMENT OF LGPL COMPONENTS

The corresponding upstream sources for the LGPL audio components are linked
above and retained in the source project. The install ZIP includes license
texts; it excludes source archives and JSON lock files.

JOrbis and JLayer source JARs contain ordinary Java sources. Compile the
sources with a Java compiler, preserve non-Java resources such as sfd.ser,
and package the resulting classes/resources as a JAR. Their supplied POMs
describe the upstream build. Replace the corresponding separate JAR in
runtime/lib, maintaining its filename or adjusting the launcher classpath.

OpenAL Soft sources include their own CMake build and documentation. An
AArch64 Linux replacement can be built with CMake and a matching toolchain
and system headers. Replace the libopenal.so entry in the separate LWJGL
OpenAL native JAR, or use LWJGL's OpenAL library-name/library-path settings
to load a compatible replacement shared library.

The port places no restriction on modification of these LGPL components or
reverse engineering for debugging such modifications. No game-specific
signature verification is imposed on these libraries. The LGPL terms and
the original game rightsholders' rights remain distinct.

EXTERNAL RUNTIMES

Java and Weston are supplied separately by PortMaster/firmware runtime
downloads and are not included in this package; retain their own notices
when obtaining or redistributing them. The JDK is not bundled. dex2jar and
ASM are bundled for on-device APK preparation, with their upstream notices.
